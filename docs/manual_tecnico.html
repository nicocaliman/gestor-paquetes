1. Arquitectura del Sistema & Diagramas (Explicación)

El sistema NC Caliman es una Single Page Application (SPA) offline-first construida bajo el patrón MVC Frontend sin necesidad de compilación (*Zero-Build Runtime*). Toda la lógica reside de forma nativa en JavaScript ES Modules en src/app.js.

2.4. Módulo de Generación y Envío Transaccional de Albaranes PDF

El sistema incluye una tubería de generación y envío de albaranes oficiales en formato vectorial PDF A4 (210x297mm) sin dependencias de captura DOM:

Especificación Técnica Paso a Paso:

  1. Fase 1 (Umbralizado de Píxeles & Aspect Ratio): imageToDataURL(url, forceBlack=true) procesa la imagen ./assets/logo_van_badge_trimmed.png mediante ctx.getImageData, forzando cada píxel no transparente a negro sólido (RGB 0,0,0) y calculando dinámicamente el ratio de aspecto (w / h) para eliminar el achatamiento vertical.
  2. Fase 2 (Generación Vectorial A4 & Geometría): generateAlbaranPDFBase64() inicializa jsPDF en formato A4 (210x297mm). Aplica separaciones métricas de 2.5mm entre las barras de título grises y las cabeceras de tabla negras, y dibuja el código QR a escala 1:1 (14.5x14.5mm) centrado en una caja blanca pura (255,255,255) con 3.4mm de margen de seguridad antes del texto legal.
  3. Fase 3 (Tubería de Envío HTTP Transaccional): EmailService.js adjunta el PDF generado en Base64 junto con la hoja de cálculo CSV y realiza una petición POST a /api/send-email (Serverless Proxy en Vercel) que redirige la carga a https://api.resend.com/emails.

3. Referencia de Datos (TypeScript Models & SQL Schemas)

3.1. Modelos de Datos (Interfaces TypeScript)

interface PackageObject {
  id: string;                      // Formato: "CAL-YYYYMMDD-XXXX"
  destinatario: string;            // Nombre completo del receptor
  localidadDestinatario: string;   // Ciudad de entrega en Rumanía
  bultos: string;                  // Cantidad de bultos (ej: "4")
  weight: string;                  // Peso acumulado en kg (ej: "114.5")
  expedidor: string;               // Nombre del remitente
  localidadExpedidor: string;      // Ciudad de origen
  price: number;                   // Tarifa calculada en Euros (€)
  createdAt: string;               // Timestamp ISO-8601
}

3.2. Esquema de Base de Datos PostgreSQL (Supabase DDL)

CREATE TABLE IF NOT EXISTS public.packages (
  id TEXT PRIMARY KEY,
  destinatario TEXT NOT NULL,
  localidadDestinatario TEXT NOT NULL,
  bultos TEXT DEFAULT '1',
  weight TEXT DEFAULT '0',
  expedidor TEXT NOT NULL,
  localidadExpedidor TEXT NOT NULL,
  price NUMERIC(10,2) DEFAULT 0,
  createdAt TIMESTAMPTZ DEFAULT NOW()
);

ALTER PUBLICATION supabase_realtime ADD TABLE public.packages;
ALTER TABLE public.packages ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Permitir lectura y escritura publica" ON public.packages FOR ALL USING (true) WITH CHECK (true);
